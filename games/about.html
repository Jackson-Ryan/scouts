About this library

Built for busy meeting nights

A free, independent games finder for Beaver, Cub and Scout leaders. No accounts, no adverts, no faff — just clear games you can run tonight.

Every meeting needs a game that fits the section, the space and the time you actually have. This library is designed to get you from “what shall we play?” to a clear set of rules in under a minute.

How the library works

Games are tagged by section, length, setting, energy, noise and mess. Use the filters on the find a game page to narrow the list, then open a game for the full rules, equipment, safety notes and leader tips.

Filter by real meeting time

Quick games take 5–10 minutes, normal games 10–20, and long games 20 minutes or more. Durations are a guide, not a stopwatch.

Pick the right section

Beavers, Cubs and Scouts have different ages, abilities and attention spans. Each game lists the sections it suits best.

Save now, play later

Tap the bookmark on any game to save it in this browser. Saved games stay on your device and are easy to find on a busy night.

Print a game sheet

Open a game and use the print button for a clean sheet with the rules, equipment and safety notes — perfect for a leader’s folder.

Variants vs themed twists

Both are ways to get more from a game, but they do different jobs. Keeping them separate means you always know whether the rules have changed.

Variant

Different rules

A variant is a separate game in the library. It might change the equipment, the scoring, the number of teams or the way players are caught. It gets its own safety notes and leader tips. Snowball Siege is a variant of French v English because the throwing and rescue rules change.

Themed twist

Same rules, new story

A themed twist is inspiration only. It changes the language, props or story — pumpkins instead of balls, moon bases instead of chairs — while the rules stay exactly the same. Spider Football is a themed twist of Crab Football, not a separate game.

When you add a game, choose a variant only if the rules change. If you are just giving a familiar game a Halloween or space makeover, add it as a themed twist instead.

Keeping games safe

Your risk assessment still matters

The safety notes here are a starting point, not a substitute for your own risk assessment. Check the space, equipment and needs of your group before you play, and follow your organisation’s safeguarding and safety policies.

Look out for games that involve throwing, running, contact, blindfolds or food. Adapt them for your venue and group, and stop any game that stops feeling safe. A leader should always be able to see the whole playing area.

Adding a game

The add a game form walks you through the fields, shows a live card preview and produces a complete JSON entry. You can download the game file, download the full updated games.json, or submit it as a GitHub issue if the site is connected to a repository.

Submissions are checked by a leader before they are added. Please include realistic safety notes and adaptions, and make sure the rules are your own words. If a game is not yours, credit the source in the author field.

Themed twists

Twists are a quick way to refresh a game without learning new rules. A good twist changes the story and the props, not the structure. The theme filter finds both games that naturally suit a theme and games with a themed twist idea.

Run your own copy

This is a static site. There is no database or server to maintain: the games live in data/games.json, and the pages are plain HTML, CSS and JavaScript. Fork the repository, edit the JSON or use the form, then publish it with GitHub Pages. The included GitHub Actions check the data and can import game submissions from issues.

Full setup notes, the data schema and the command-line tools are in games/README.md, with the toolbox overview in the top-level README.md.
