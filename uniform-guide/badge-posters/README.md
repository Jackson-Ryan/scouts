# Badge Posters Staging Folder (Temporary)

Upload the official Scouts badge poster PDFs into this folder on the `t3/uniform-badge-guide` branch so they can be processed and extracted into optimised SVG badge assets.

## How to upload via GitHub

1. Click **Add file → Upload files** in this folder on branch `t3/uniform-badge-guide`.
2. Drag and drop your badge poster PDF files here.
3. Commit the upload directly to the `t3/uniform-badge-guide` branch.
4. Let me know once they are uploaded, and I will extract and optimise the individual SVGs on Colab compute.

> **Note:** This folder is temporary staging only. After the badge SVGs are extracted and wired into `uniform-guide/`, these raw PDFs and this folder will be removed before merging to `main` so large source PDFs are not deployed to GitHub Pages.
